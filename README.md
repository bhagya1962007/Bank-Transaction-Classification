# Bank Transaction Classification using Scikit-learn

A machine learning project that classifies bank transactions into different categories using a Random Forest Classifier. The project uses transaction-related features such as transaction amount, transaction time, account balance, merchant type, and transaction channel to predict the category of a transaction.

## Project Overview

Bank transactions can belong to different categories such as:

* Groceries
* Bills
* Shopping
* Travel
* Salary
* Entertainment

This project applies supervised machine learning to automatically classify transactions based on their characteristics.

The project includes model training, evaluation, prediction, feature importance visualization, and an interactive Streamlit web application.

## Features

* Bank transaction classification using machine learning
* Random Forest classification algorithm
* Training and testing dataset split
* Model performance evaluation
* Classification report and confusion matrix
* Feature importance visualization
* Prediction confidence score
* Pre-trained model saved using Joblib
* Interactive Streamlit application
* Dataset preview through the web interface

## Machine Learning Model

The project uses the `RandomForestClassifier` from Scikit-learn.

### Model Configuration

```python
RandomForestClassifier(
    n_estimators=200,
    max_depth=10,
    random_state=42,
    class_weight="balanced"
)
```

The dataset is divided into training and testing sets using an 80/20 split.

## Features Used

The model uses the following input features:

| Feature               | Description                                             |
| --------------------- | ------------------------------------------------------- |
| `amount`              | Transaction amount                                      |
| `transaction_hour`    | Hour at which the transaction occurred                  |
| `is_weekend`          | Indicates whether the transaction occurred on a weekend |
| `account_balance`     | Account balance at the time of transaction              |
| `merchant_type`       | Merchant category/type code                             |
| `transaction_channel` | Transaction channel such as Online/UPI, POS, or ATM     |

The target variable is:

```text
category
```

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd Bank_Transaction_Classification_Sklearn
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Train the Model

Run the following command to train the Random Forest model:

```bash
python train_model.py
```

The training script:

1. Loads the transaction dataset.
2. Selects the required features.
3. Splits the data into training and testing sets.
4. Trains the Random Forest Classifier.
5. Generates predictions on the test dataset.
6. Calculates accuracy and classification metrics.
7. Displays the confusion matrix.
8. Saves the trained model.
9. Generates a feature importance chart.

The trained model is saved as:

```text
models/bank_transaction_classifier.pkl
```

The feature importance chart is saved as:

```text
outputs/feature_importance.png
```

## Make a Prediction

After training the model, run:

```bash
python predict.py
```

The prediction script loads the trained model and classifies a sample transaction.

Example input:

```python
transaction = pd.DataFrame([{
    "amount": 1250,
    "transaction_hour": 18,
    "is_weekend": 0,
    "account_balance": 45000,
    "merchant_type": 1,
    "transaction_channel": 1
}])
```

The script returns the predicted transaction category and prediction confidence.
